Kratt PSX Horror Game
Ülevaade

Kratt PSX Horror Game on low-poly PSX stiilis horror-mäng Eesti folkloori põhjal.

Mängija eesmärk on leida kõik kadunud loitsulehe tükid, vältida samal ajal Kratti ning viia need lõpuks ohvrikivile. Alles siis saab Krati hävitada ja külast põgeneda.

Mäng keskendub atmosfäärile, pingele ja ellujäämise tundele.
