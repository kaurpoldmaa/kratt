Kratt PSX Horror Game
Ülevaade

Kratt PSX Horror Game on madala polüarvuga (low-poly) PSX stiilis atmosfääriline mäng, mis on inspireeritud Eesti folkloorist ja eriti Krati legendist.

Mäng ühendab vana PlayStation 1 ajastu visuaalse stiili, süngema metsa-atmosfääri ja rahvapärimusest pärit müstika.

Eesmärk on luua pingeline ja meeldejääv kogemus, kus mängija peab uurima ümbrust, avastama saladusi ning ellu jääma kohtumistes üleloomulike jõududega.
